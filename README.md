# Ayat

Құран оқу және жаттау: https://vertex-blip.github.io/ayat/

604 бет, 114 сүре. Қара/ақ тақырып. Аяттарды жасыру. Құран беттерінің оңнан солға реті: саусақты оңға сырғыту келесі бетке өткізеді.

Телефон: Safari/Chrome дауыс қызметі, үлкен модель жүктелмейді. Аудио браузер провайдерінің серверінде өңделуі мүмкін, интернет қажет болуы мүмкін. iPhone-да Safari-де ашып, Siri-ді қосып, микрофон/дауысты тануға рұқсат беріңіз. Қолдауы жоқ мобильді браузерде ауыр модель қосылмайды.

Компьютер браузері: шамамен 300 МБ Quran Whisper моделі бірінші рет жүктеледі. Бұл режим аудионы құрылғыда өңдейді. Телефонның жалпы дауыс қызметі Құранға арналған модельдей дәл болмауы мүмкін.

Интернет нұсқасы ықтимал сөз қателерін тексереді; харакат/тәжуидтің Python режимі компьютерге орнатылатын нұсқада ғана бар. Нәтижелер қателесуі мүмкін.

Деректер: [QUL / QPC V4](https://github.com/hussainsajib/qpc-v4-mushaf-bundle), [Tanzil](https://tanzil.net/) (CC BY 3.0), [Madinah Mushaf JSON](https://github.com/ouryhamdalaye/madinah-mushaf-json) (CC BY-SA 4.0). QPC қаріптері түпнұсқа жинақтың CDN мекенжайынан жүктеледі.

Дауысты тану: [Tarteel Quran Whisper ONNX](https://huggingface.co/eventhorizon0/tarteel-ai-onnx-whisper-base-ar-quran), Apache 2.0. Браузер кітапханаларының лицензиялары vendor папкасында.
