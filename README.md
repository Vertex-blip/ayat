# Ayat

Құран оқу және жаттау: https://vertex-blip.github.io/ayat/

604 бет, 114 сүре. Қара/ақ тақырып. Аяттарды жасыру. Құран беттерінің оңнан солға реті: саусақты оңға сырғыту келесі бетке өткізеді.

Микрофонмен кез келген жерден оқуды бастауға болады. Бірмәнді тіркес танылғанда қосымша Құраннан сол орынды тауып, тиісті бетті ашады; қайталанатын тіркестердің жалғасын күтеді. Орын анықталғаннан кейін басқа аятқа не сүреге ауыспайды. Қате танылған немесе оқылмай қалған сөзде тоқтап, белгі көрсетеді; сол сөз дұрыс оқылғанда ғана жалғасады. Мәтінді ретімен оқып келесі бетке жеткенде ол автоматты ашылады. Басқа жерден бастау үшін микрофонды тоқтатып, қайта қосыңыз. Бұл нәтиже сөздің қате оқылғанын дәлелдемейді.

Мәтін толық ашық тұрғанда да соңғы танылған сөз бен жол көкпен белгіленеді. Нақтылауды күткен сөздің асты көк үзік сызықпен сызылады. Сөз анық танылмаса, ол оқу қатесі деп есептелмейді, қате санағын өсірмейді және діріл бермейді. «Тексеру» ішінде күтілгені мен танылғаны көрсетіледі. Қызмет ұсынған беске дейінгі нақты балама мәтін, емле баламалары мен аятты қайта оқу ескеріледі. Бұл интернет режимі сөз деңгейінде салыстырады; мәд ұзындығы мен тәжуидті дыбыстан бағалау компьютердегі бөлек терең тексеруде ғана бар.

Телефон: Safari/Chrome дауыс қызметі, үлкен модель жүктелмейді. Аудио браузер провайдерінің серверінде өңделуі мүмкін, интернет қажет болуы мүмкін. iPhone-да Safari-де ашып, Siri-ді қосып, микрофон/дауысты тануға рұқсат беріңіз. Қолдауы жоқ мобильді браузерде ауыр модель қосылмайды.

Компьютер браузері: шамамен 300 МБ Quran Whisper моделі бірінші рет жүктеледі. Бұл режим аудионы құрылғыда өңдейді. Телефонның жалпы дауыс қызметі Құранға арналған модельдей дәл болмауы мүмкін.

Интернет нұсқасы ықтимал сөз қателерін тексереді; харакат/тәжуидтің Python режимі компьютерге орнатылатын нұсқада ғана бар. Нәтижелер қателесуі мүмкін.
